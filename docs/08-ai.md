# AI

## Role

AI exists to reduce cognitive load.

It is not the product's primary value. Work Memory must still be valuable when AI is unavailable, disabled, or wrong.

## Allowed assistance

AI can help with:

- Summarizing entries.
- Suggesting classification after capture.
- Highlighting decisions, blockers, or open questions.
- Helping reconstruct a day from a Work Log.
- Making captured context easier to review.

## Forbidden assistance

AI should not:

- Interrupt capture.
- Require the user to answer questions before saving an entry.
- Invent facts that are not present in the user's entries.
- Turn entries into plans by default.
- Replace the user's judgment.

## Product rule

AI suggestions are optional.

The user owns the memory. AI can help organize or interpret it, but it must not create a false sense of certainty.
