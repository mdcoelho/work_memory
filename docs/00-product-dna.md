# Product DNA

## Why this product exists

Modern knowledge workers lose context because work rarely happens in a straight line.

Their day is fragmented by meetings, messages, documents, decisions, urgent requests, and unfinished thoughts. They move between contexts before their previous context has been fully recorded.

The result is not only missed tasks. It is lost professional memory: what happened, why it mattered, what changed, and where work should resume.

Work Memory exists to preserve that context with as little effort as possible.

## The problem

People remember what they have to do.
They don't remember what they actually did.

This creates friction every time they return to work after an interruption. They must reconstruct their own activity from memory, chats, files, calendars, and task lists.

That reconstruction is slow, incomplete, and mentally expensive. The product starts from this problem, which is expanded in [Problem Statement](02-problem-statement.md).

## Vision

Build a Work Memory, not a task manager.

A task manager organizes future commitments. Work Memory preserves the user's professional context so they can understand what happened, recover momentum, and explain their work.

The product should feel like a fast memory layer: always available, easy to capture into, and useful when the user needs to resume, explain, decide, or hand off work. The long-term direction is described in [Vision](01-vision.md).

## Non-negotiable principles

- Capture in seconds.
- Organize later.
- Context is more important than folders.
- AI reduces cognitive load.
- Classification can happen later.
- Work logs are more important than timers.
- The application should never feel bureaucratic.
- Every interaction must save time.

## This product is NOT

It is not:
- Jira
- ClickUp
- Notion
- CRM
- Wiki
- Project management software

Work Memory must never become another ClickUp or Jira. It should not optimize for process administration, complex workflows, status management, or team bureaucracy.

The purpose of Work Memory is to become the user's professional memory.
