# Product DNA

## Why this product exists

Modern knowledge workers lose context because work rarely happens in a straight line. Meetings, messages, urgent requests, documents, decisions, and half-finished thoughts compete for attention all day.

The result is not only missed tasks. It is lost context: why something changed, what was already tried, what was decided, and where the work should resume.

Work Memory exists to preserve that context with as little effort as possible.

## The problem

People remember what they have to do.
They don't remember what they actually did.

This creates friction every time they return to work after an interruption. They must reconstruct their own activity from memory, chats, files, calendars, and task lists.

That reconstruction is slow, incomplete, and mentally expensive.

## Vision

Build a Work Memory, not a task manager.

A task manager tells the user what is pending. Work Memory helps the user recover what happened, what matters, and what context should come forward.

The product should feel like a fast professional memory layer: always available, easy to capture into, and useful when the user needs to resume, explain, decide, or hand off work.

## Non-negotiable principles

- Capture in seconds.
- Organize later.
- Context is more valuable than structure.
- AI reduces cognitive load.
- The application should never feel bureaucratic.
- Every interaction must save time.

## This product is NOT

It is not:
- Jira
- ClickUp
- Notion
- CRM
- Wiki
- Project management software

The purpose of Work Memory is to become the user's professional memory.
