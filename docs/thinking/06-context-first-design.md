# Context-First Design

## Product philosophy

Work Memory is not a task manager.

It is not a work log.

It is not notes.

It is not time tracking.

Those forms can appear around the work, but none of them define the product's mental model.

Work Memory is a Context Operating System.

## What Context Operating System means

A Context Operating System treats context as the primary unit of work.

It preserves the human continuity between people, problems, artifacts, decisions, conversations, and unfinished states.

It is concerned with what the founder is actually holding in mind, not where the evidence happens to be stored.

## Principle 1: Context before containers

Records, files, messages, meetings, and models are containers.

The product should understand them as evidence inside a context, not as the context itself.

## Principle 2: Identity before naming

Context identity survives bad names, old names, temporary labels, and renamed work.

The product should protect the underlying thread even when vocabulary changes.

## Principle 3: Relationships before hierarchy

Context is relational.

Customer, supplier, product, problem, decision, artifact, and conversation form meaning through their connections.

A folder-like hierarchy cannot represent the founder's real mental model.

## Principle 4: Recovery before organization

The purpose of preserving context is recovery.

Organization is useful only when it helps the founder return to the context, explain it, or decide within it.

## Principle 5: Meaning before chronology

Order matters, but chronology alone is not enough.

The founder needs to know which events changed the context, which decisions still matter, and what the current state means.

## Principle 6: Continuity before completeness

The product does not need to preserve everything.

It needs to preserve enough continuity that the founder can re-enter the context without reconstructing it from scattered evidence.

## Principle 7: Assistance without interruption

Assistance is valuable only when it lowers the cost of holding, recovering, or explaining context.

Assistance becomes harmful when it interrupts the founder or adds a second layer of work.

## Principle 8: Context over productivity theatre

The product should not optimize for visible busyness, status ceremony, or process compliance.

It should optimize for the founder's ability to understand the current context and return to it later.

## Final stance

The purpose of Work Memory is to preserve context identity across interruption, time, and changing names.
