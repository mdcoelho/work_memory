# MVP

## Scope

This is the smallest product that can launch in 90 days.

The MVP exists only to prove the core loop:

1. Open.
2. Capture work.
3. Return to work.
4. Recover context.
5. Review the day.
6. Report work.

## Required Features

### 1. Fast context capture

The user can capture context in less than 5 seconds.

Capture accepts plain language and does not require classification.

### 2. Automatic timestamp

Every capture records when it happened.

This is required for day review, recovery, and date-range reporting.

### 3. Recent context evidence

The user can see recent captured evidence immediately after opening the product.

This is required for quick recovery after interruption.

### 4. Context naming after capture

The user can name or rename a context after capture.

This is required because names change and classification should not block capture.

### 5. Connect capture to context after capture

The user can connect a capture to an existing context after the memory is saved.

This is required because context identity matters more than the first label.

### 6. Resume point

The user can preserve where work stopped.

This is required for recovery after 30 minutes, tomorrow, or 3 weeks.

### 7. Day review

The user can review what changed today by context.

This is required before reporting can be trusted.

### 8. Date-range report

The user can ask what happened between two dates.

The answer is organized by context and includes decisions, blockers, changes, resume points, and supporting evidence.

### 9. Search

The user can search preserved context evidence.

This is required when the user remembers a person, product, supplier, problem, or phrase but not the context name.

### 10. Manual correction

The user can edit captured evidence, context names, and report wording.

This is required because memory must remain trustworthy.

## Explicit MVP Boundary

The MVP does not need collaboration, automation, integrations, dashboards, complex classification, or advanced assistance.

If a capability does not directly protect capture, recovery, review, or reporting, it is not part of launch.
