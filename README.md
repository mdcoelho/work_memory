# Work Memory

Work Memory is a fast professional memory system for knowledge workers who constantly change context.

It is not a task manager. It helps users capture what happened, recover context, and understand their work without maintaining another management system.

The first target user is the project founder. The research documents summarize observed founder behavior extracted from this repository.

Start with [AGENTS.md](AGENTS.md), then read the research documentation under [docs/research](docs/research).
