# Work Memory

Work Memory is a fast professional memory system for the founder, who constantly changes professional context.

It is not a task manager. It helps the founder capture what happened, recover context, and understand work performed without maintaining another management system.

The first target user is the project founder. The research and case documents summarize observed founder behaviour extracted from this repository.

Start with [AGENTS.md](AGENTS.md), then read [docs/research](docs/research) and [docs/cases](docs/cases).
