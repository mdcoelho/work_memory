# Work Memory

Work Memory is a fast professional memory system for preserving context.

It is not a task manager, work log, notes system, or time tracker. It helps the founder recover the human context behind work without maintaining another management system.

The first target user is the project founder. The research and case documents summarize observed founder behaviour extracted from this repository.

Start with [AGENTS.md](AGENTS.md), then read [docs/thinking](docs/thinking), [docs/research](docs/research), and [docs/cases](docs/cases).
