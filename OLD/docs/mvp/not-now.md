# Not Now

## Scope

Everything in this file is outside the 90-day MVP.

These items may be useful later, but they are not required to prove the core loop.

## Not In MVP

- Team collaboration.
- Shared workspaces.
- Permissions.
- Comments.
- Notifications.
- Reminders.
- Calendar sync.
- Email sync.
- Business record sync.
- File or artifact sync.
- Automatic context detection.
- Automatic classification.
- Complex tags.
- Folder systems.
- Project dashboards.
- Boards.
- Status workflows.
- Assignments.
- Timers.
- Billing or invoicing.
- CRM behaviour.
- Wiki behaviour.
- Templates.
- Rich document editing.
- Attachments.
- Voice capture.
- Mobile-specific behaviours.
- Offline conflict handling.
- Advanced export formats.
- Analytics.
- Productivity scoring.
- AI-generated plans.
- AI agents that act on work.
- AI suggestions during capture.
- Multi-user reporting.
- Custom workflows.
- Integrations marketplace.
- Admin settings.

## Rule

If a feature is not necessary for fast capture, context recovery, day review, or date-range reporting, it stays out of the MVP.
