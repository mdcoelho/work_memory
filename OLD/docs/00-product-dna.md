# Product DNA

## Why this product exists

The founder loses context because work rarely happens in a straight line.

Their day is fragmented by meetings, messages, documents, decisions, urgent requests, and unfinished thoughts. They move between contexts before the previous context identity has been preserved.

The result is not only missed tasks. It is lost professional memory: what the context was, why it mattered, what changed, and where it should resume.

Work Memory exists to preserve that context with as little effort as possible.

## The problem

People remember what they have to do.
They don't remember what they actually did.

This creates friction every time they return after an interruption. They must reconstruct the context from scattered artifacts, conversations, meetings, records, files, and memory.

That reconstruction is slow, incomplete, and mentally expensive. The problem is expanded in [Problem Statement](02-problem-statement.md).

## Vision

Build a Work Memory, not a task manager.

A task manager organizes future commitments. Work Memory preserves context so the founder can understand the situation, recover momentum, and explain work performed.

The product should behave like a Context Operating System: preserving the human continuity between people, problems, artifacts, decisions, conversations, and unfinished states. The long-term direction is described in [Vision](01-vision.md) and [Context-First Design](thinking/06-context-first-design.md).

## Principles

- Capture in seconds.
- Organize later.
- Context identity is the fundamental unit.
- Containers are not contexts.
- AI reduces cognitive load.
- Classification can happen later.
- Chronology is useful only when it helps recover context.
- Entries are captured evidence, not the product's mental model.
- The product should not feel bureaucratic.
- Every interaction should save time.

## Boundaries

It is not:
- Jira
- ClickUp
- Notion
- CRM
- Wiki
- Project management systems

Work Memory should not become another ClickUp or Jira. It should not optimize for process administration, complex workflows, status management, or team bureaucracy.

The purpose of Work Memory is to become the founder's professional memory.
