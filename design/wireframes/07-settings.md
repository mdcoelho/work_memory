# Settings

## Screen Status

Removed from MVP.

Settings is not required to prove capture, recovery, review, or reporting.

## Purpose

No standalone Settings purpose exists for the MVP.

If a preference becomes required before launch, it should be handled by a simple default rather than a settings screen.

## ASCII Wireframe

```text
+----------------------------------------------------------------------------+
| Settings                                                                    |
+----------------------------------------------------------------------------+
| Removed from MVP                                                            |
|                                                                            |
| No settings are required for fast capture, context recovery, day review,    |
| or date-range reporting.                                                    |
+----------------------------------------------------------------------------+
| Esc home                                                                    |
+----------------------------------------------------------------------------+
```

## Information Shown

- Statement that Settings is not part of MVP.
- No preferences.
- No configuration.

## User Actions

- Return Home.

## Keyboard Shortcuts

- `Esc`: Home.

## Navigation

- No navigation should lead to Settings in the MVP.
- This file exists only to record the screen removal decision.

## Empty State

Settings itself is the empty state.

There are no MVP settings to configure.

## Loading State

No loading state is needed because Settings is removed.

## Error State

No error state is needed because Settings is removed.

## MVP Review

Settings is removed from the final MVP.

Adding it would create setup and maintenance before the product has proven the core loop.
